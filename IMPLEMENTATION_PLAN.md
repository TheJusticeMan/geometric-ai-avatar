# Implementation Roadmap

## Phase 1: Static Foundations (The "Sketch" Phase)

- [ ] Develop `AvatarParser.js` to render JSON into a `<svg>` container.
- [ ] Create basic "Default" character JSON.
- [ ] Implement browser-based live-reload preview.

## Phase 2: Temporal Agency (The "Breath" Phase)

- [ ] Integrate `Anime.js` for JSON-driven tweening.
- [ ] Build a "Blink" and "Float" animation loop.
- [ ] Implement "Animation Triggers" based on text input length.

## Phase 3: The Reflective Loop (The "Self" Phase)

- [ ] Create the `Mirror.js` module to summarize the SVG state into text.
- [ ] System Prompt Engineering: Teach the LLM to update its `character.json` via chat.
- [ ] Persistence: Save the LLM's "evolved" look to a local database.

## Phase 4: Advanced Interaction (The "Presence" Phase)

- [ ] Add "Physics-Lite": Drag-and-drop body parts that snap back.
- [ ] Multi-agent support: Different JSON files for different personalities.
